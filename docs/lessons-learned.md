# Lessons Learned

Living log of things that went wrong or surprisingly right, and the rule they produced.
Generic lessons (not tied to this project) are tagged **[KIT]** and get promoted into the
`project-kickstart` plugin during the retrospective.

| Date | Context (task / conversation) | What happened | Rule / fix adopted | Scope |
|---|---|---|---|---|
| 2026-10-31 | packaging & release | Releasing multiple executables in distribution bundles confused users and complicated shortcuts | Distribute a single standalone setup executable (`<AppName>-Setup.exe`) and a clean single-binary portable zip | [KIT] |
| 2026-10-31 | UX & In-App Maintenance | Users had no way inside GUI applications to re-run setup, create shortcuts, or trigger uninstallation | Provide in-app maintenance controls (shortcuts, repair, uninstall) and progressive 5-step Setup Wizard | [KIT] |
| 2026-10-27 | Autonomous UI & A11y QA (`ui-qa-tester`) | Embedded web renderers (WebView2/Chromium) delay UIA tree hydration and ignore input messages sent to top-level frames | Walk child HWND trees (depth $\ge$ 15), warm up UIA with a brief 300ms pause, convert coordinates via `ScreenToClient(render_hwnd)`, and calculate contrast on small labels | [KIT] |
| 2026-10-27 | Live QA on Native GUIs (`eframe`/`egui`) | Calling `IUIAutomationElement::GetCurrentPattern` on structural/container elements triggered 2-second MSAA proxy timeouts | Filter `GetCurrentPattern` queries by interactive `UIA_ControlType` IDs, reducing walk latency from ~2,000ms to <15ms | [KIT] |
| 2026-10-27 | DWM Window Bounds Calibration | Windows 11 drop shadow margins (~8px) skew `GetWindowRect` offsets relative to visible client content | Call `DwmGetWindowAttribute(DWMWA_EXTENDED_FRAME_BOUNDS)` to extract true visible window bounds, falling back to `GetWindowRect` | [KIT] |
| 2026-10-27 | Web/Frontend Component Architecture | Single-page views overgrown to 2,500+ lines caused hydration latency and cognitive overload for agents | Decompose page into dedicated tab components (`src/components/tabs/`) and synchronize active tab/filters with URL search parameters (`?tab=...`) | [KIT] |
| 2026-10-25 | Documentation Parity for Multi-Channel Distribution | After adding WinGet/Scoop manifests and setup scripts, documentation still pointed to raw source build directories | Whenever adding or modifying distribution channels, synchronize `README.md`, `docs/user-guide.md`, and `docs/release-methodology.md` in the same commit | [KIT] |
| 2026-10-25 | PowerShell External CLI UTF-8 Encoding | External CLI stdout capture (`gh`, `git`) on Windows PowerShell mangled non-ASCII Unicode characters | Set `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8` and force UTF-8 without BOM before capturing CLI output | [KIT] |
| 2026-10-25 | PowerShell Pipeline Binding Trap | Piping `gh api` output directly into static .NET methods (`[System.Text.Encoding]::UTF8.GetString($input)`) caused PowerShell to hang | Never pipe directly into static .NET methods in PowerShell; use `gh api -H "Accept: application/vnd.github.raw"` or assign to a variable first | [KIT] |
| 2026-10-25 | Windows COM / Win32 RAII Integration | Windows COM interface pointers (e.g. `IMMDeviceEnumerator`) drop after `CoUninitialize()` if in outer scope, causing access violations | Explicitly scope COM objects in an inner block so RAII drops interfaces before `CoUninitialize()`, and free string buffers via `CoTaskMemFree` | [KIT] |
| 2026-10-25 | GitHub Governance & Portable Releases | Binary executables remained only in local ignored build directories without tracked issues or downloadable GitHub Releases | Map every roadmap milestone to a GitHub Milestone and tracked GitHub Issues; attach pre-built `.zip` bundles to GitHub Releases even while hardware QA is `Pending` | [KIT] |
| 2026-10-25 | Multi-Process & Test Concurrency | Automated tests touching global OS resources (pipes, sockets, registry, hooks) collided during parallel test execution | Use unique GUID/timestamp identifiers, isolated thread runners (`--test-threads=1`), and timeout protection to prevent test hangs | [KIT] |
